# run

完成物を**実行・運用するための入口**（ランチャ・バッチ）を置くフォルダ（git 管理）。

- 想定する中身：ツールを動かすためのバッチ/シェルスクリプト、薄いランチャ（例: `run_app.bat`）。
  中身は `uv run python -m <pkg> ...` を呼ぶだけにする。
- `examples/`（このパッケージの**使い方**を示すデモ）や `src_dev/`（**開発中**に使う補助コード）とは別で、
  **日々の運用でツールを動かすための入口**を集める。
- `output/`（生成物・ランタイム状態）と語感が近いので、ここは「動かす入口」だと README で住み分ける。
- 空でも構わない（運用バッチが要るときに使う）。
